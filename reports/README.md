# Reports

Generated by `make train` and `make evaluate` (git-ignored). Start with `results.md`.
When `data_source` is `demo`, every report is labelled DEMO and must not be quoted as Olist performance.

| File | Written by | Content |
|---|---|---|
| `results.md`, `results.json` | evaluate | test comparison, confusion matrix, findings, drift, SHAP top features |
| `model_comparison_validation.csv` / `_test.csv` | train / evaluate | baselines vs LightGBM |
| `threshold_analysis_validation.csv` | train | precision, recall, FP, FN, assumed cost by threshold |
| `calibration_*` | train / evaluate | method comparison and reliability curves |
| `shap_summary.png`, `shap_global_importance.csv` | evaluate | global explanations |
| `error_analysis_segments.csv` | evaluate | FP/FN by segment |
| `drift_report.csv` | evaluate | PSI/KS train -> test |
| `split_report.json`, `class_imbalance.json`, `feature_audit.json` | features / train | split cutoffs, monthly volume, class ratios |
