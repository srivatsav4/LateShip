# Models

Generated by `make train` (git-ignored). Contents:

* `lateship_model.pkl` - LightGBM + fitted calibrator (`RiskModel`)
* `threshold.json` - operating threshold, alternative thresholds, cost assumptions, risk cutoffs and actions
* `feature_schema.json` - features, categorical vocabularies, descriptions
* `metadata.json` - version, training period, feature count, hyperparameters, calibration method, validation metrics; `test_metrics` is filled by `make evaluate` (until then it says "not evaluated yet")
* `comparison_models.pkl` - baselines and LightGBM variants used for the comparison table

Pickles are tied to the library versions in `requirements*.txt`; retrain after upgrading them.
